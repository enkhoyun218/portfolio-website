## Run locally

This project is built with Gatsby 4 and needs Node 14.16.0 (see `.nvmrc`).

```sh
nvm install
yarn
npm start
```

Build and preview a production version:

```sh
npm run build
npm run serve
```

## Where content lives

- `gatsby-config.js` and `src/config.js`: site metadata, email, social links
- `src/components/sections/hero.js` and `about.js`: hero and about text
- `content/jobs/`: work experience
- `content/featured/`: featured projects
- `static/resume.pdf`: resume
