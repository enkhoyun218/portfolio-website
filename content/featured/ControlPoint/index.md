A web app that estimates a company's SOC 2 Type II readiness. It scores 55 modeled security controls, flags segregation-of-duties conflicts across 62 employees, and includes an AI assistant that answers questions about the results. All company data in the demo is synthetic, and it is an educational tool, not an audit.
